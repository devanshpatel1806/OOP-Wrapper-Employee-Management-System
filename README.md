# OOP Wrapper - Employee Management System

## 1. Project Overview

The **OOP Wrapper - Employee Management System** is a Python-based console application created to demonstrate important Object-Oriented Programming (OOP) concepts.

The program allows the user to create different types of objects such as Person, Employee, Manager, and Developer. It provides a simple menu-driven interface to create and display their details.

---

## 2. Objective

The main objective of this project is to understand and implement Object-Oriented Programming concepts using Python.

The project demonstrates:

- Classes and Objects
- Constructor
- Destructor
- Inheritance
- Multilevel Inheritance
- Encapsulation
- Getter and Setter methods
- Method Overriding
- `super()`
- `self`
- `isinstance()`
- `issubclass()`

---

## 3. Technologies Used

- Python 3
- VS Code / Python IDLE
- Console-based application

No external libraries are required.
## 4. OOP Concepts Demonstrated
### Classes and Objects

Classes are used to create objects for Person, Employee, Manager, and Developer.

### Constructor

The __init__() method is used to initialize object attributes.

### Inheritance

Employee inherits from Person, while Manager and Developer inherit from Employee.

### Encapsulation

Employee ID and salary are stored as private attributes.

### Getter and Setter

Getter methods are used to access private data and setter methods are used to modify it.

### Method Overriding

The display() method is overridden in the Manager and Developer classes.

### super()

The super() function is used to access methods of the parent class.

### self

The self keyword refers to the current object.

### isinstance()

isinstance() is used to check whether an object belongs to a particular class.

### issubclass()

issubclass() is used to check whether one class is derived from another class.

### Destructor

The __del__() method is used as a destructor.

## 6. Program Features
### Create a Person

The user enters:

-Name
-Age

A Person object is created.

### Create an Employee

The user enters:

-Name
-Age
-Employee ID
-Salary

An Employee object is created.

### Create a Manager

The user enters:

-Name
-Age
-Employee ID
-Salary
-Department

A Manager object is created.

### Create a Developer

The user enters:

-Name
-Age
-Employee ID
-Salary
-Programming Language

A Developer object is created.

### Show Details

This option displays the details of all objects created during program execution.

### Check OOP Concepts

This option demonstrates inheritance using issubclass().
